# About Hospitia

Hospitia is a web application for running guest houses owned or managed by non-profit organizations (NGOs). It gives each organization one place to manage its properties, rooms and staff. It is built as a set of small services so that features such as booking, payment and dashboards can grow independently.

This section explains the project rather than how to use or change it:

- [Vision and mission](vision.md): the problem Hospitia addresses and who it is for.
- [Features](features.md): what Hospitia can do today.
- [Roadmap](roadmap.md): where the project is heading.
- [Glossary](glossary.md): the domain terms used in the code, the UI and these docs.

## Project status

Hospitia is in active early development. There is no tagged release yet; the [changelog](../changelog.md) records a `0.1.0` baseline of what has been built so far. The repositories are private for now; the documentation is written to the standard of a public open-source project so that publishing later needs only licensing and contact details to be finalized.
