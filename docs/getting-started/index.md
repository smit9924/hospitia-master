# Getting started

This section takes you from a clean machine to Hospitia running locally. Follow the pages in order.

1. [Prerequisites](prerequisites.md): tools and access you need.
2. Set up a workspace, either:
    - [Local setup (dev container)](local-setup.md), the standard setup on your own machine; or
    - [Claude Code cloud sessions](cloud-sessions.md), for working with Claude Code on claude.ai.
3. [Running the app](running-the-app.md): start the backend services and the frontend.
4. [Local services and credentials](local-services.md): Postgres, PgAdmin, RabbitMQ and Mailpit.
5. [Troubleshooting](troubleshooting.md) when something doesn't work.

When the app is running, take the [Product tour](../tutorials/product-tour.md) to see the main features end to end.
