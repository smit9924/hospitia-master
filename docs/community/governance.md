# Governance

How the project is run.

## Maintainers

Maintainers review and merge pull requests, triage issues, cut releases and run the CI and production servers.

## How decisions are made

- Day-to-day changes are decided in pull requests: a maintainer's approval is needed to merge.
- Changes to [Standards](../standards/index.md) are proposed in a pull request that updates the standard (and the matching agent rule).
- Significant architectural decisions are recorded as [architecture decision records](../adr/index.md).
- The [roadmap](../about/roadmap.md) is maintained by the maintainers.

## Access

The repositories are private for now. Ask a maintainer for access to all three repositories (`hospitia-master`, `hospitia-frontend`, `hospitia-backend`).
