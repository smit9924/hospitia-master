# Support

Where to get help and how to report problems.

## Ask a question or report a problem

Open an issue in the repository the problem belongs to; each repository has templates for bug reports, feature requests and documentation issues.

| Problem with… | Repository |
|---|---|
| The web app (pages, forms, styling) | [hospitia-frontend issues](https://github.com/smit9924/hospitia-frontend/issues) |
| An API, emails, data or a backend service | [hospitia-backend issues](https://github.com/smit9924/hospitia-backend/issues) |
| Setup, dev container, CI/CD, deployment or documentation | [hospitia-master issues](https://github.com/smit9924/hospitia-master/issues) |
| Not sure | [hospitia-master issues](https://github.com/smit9924/hospitia-master/issues) |

Before you open an issue:

- check [Troubleshooting](../getting-started/troubleshooting.md) and search existing issues;
- include what you did, what you expected, what happened, your role (admin, owner, manager, customer), and any `errorCode` or `X-Request-ID` from the failing response;
- never paste passwords, tokens or `.env` contents.

## Security problems

Don't open a public issue for a vulnerability. Follow the [security policy](https://github.com/smit9924/hospitia-master/blob/main/SECURITY.md).
