# Tutorials

Tutorials teach by walking you through a complete task from start to finish. Do them in order the first time; each one takes 20–45 minutes.

| Tutorial | You'll learn |
|---|---|
| [Product tour](product-tour.md) | What Hospitia does, by setting up an organization with rooms as each role |
| [Your first backend endpoint](first-backend-endpoint.md) | The backend layering end to end: schema, repository, service, route, access control, API reference |
| [Your first frontend page](first-frontend-page.md) | Adding a page: route, guard, service call, component, styles, accessibility, translation |
| [Your first message flow](first-message-flow.md) | Publishing an event through the messaging abstraction and consuming it in another service |

Before you start, complete [Getting started](../getting-started/index.md) so the infrastructure is running. The code tutorials are exercises: work on a throwaway branch and don't open a pull request for the example code.
